## JANA KYLE A T H250032B O.O.P LABS 
Each Lab folder is self-contained.
Class names repeat between labs
(Student, Temperature, Circle ...), so always run a lab from inside its own folder:
    cd Lab1
    java Lab1                 

To recompile from source (JDK needed):
    javac *.java
    java Lab1 -10 

    ## For the mini project 
    javac *.java        # compile
    java LibraryApp     # run the app
    java LibraryTest
